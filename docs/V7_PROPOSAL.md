# After V6: replicate the gain, then test robustness

Status: proposal only. No new training, inference or allocation has been submitted.

V6 improves complete fresh worlds from 21/360 to 214/360, a 53.61-point gain with a blocked 95% interval of 48.61–58.34 points. Both declared UNKNOWN-retention checks pass. This is one matched seed pair. Control selected its original weights; treatment selected its final checkpoint. The result supports the selected multi-entity training pipeline on this synthetic distribution, not a general decision engine or an identified internal reasoning mechanism.

Only 9/360 families are correct across every transformation. The preselected example misses a TRUE-to-UNKNOWN support removal. Post hoc edit slices separate two problems: getting the base evidence wrong and failing to react correctly when it changes. Distractors, ordering and old-style wording/single-branch transfer remain weaknesses. More parameter count alone is not yet a tested explanation.

## Hypothesis after replication

If the gain repeats but transformations remain fragile, compare ordinary cross-entropy against one explicit pair-consistency objective using identical paired examples and starting weights. Require correct answers before and after a local edit, and check that unaffected entities remain correct. Consistency alone can reward two wrong answers, so retain both-answer correctness and complete-world accuracy as checks.

Choose the exact objective from training/development evidence, then freeze it before fresh tests. The existing V6 test breakdown is hypothesis-generating evidence. Changing the loss, pair batching, data mixture and architecture simultaneously would prevent attributing the result.

A later architecture experiment needs a matched baseline and its own scope. The earlier tiny scratch model's chance-level result remains preserved; this V6 result does not overturn it. The useful next question is whether a controlled change improves faithful reactions to evidence while preserving the demonstrated multi-entity gain.
