## Question

Does label-aligned Jensen–Shannon consistency improve correct decisions before and after a local edit beyond cross-entropy on the identical paired examples?

## Objective and matched exposure

Consecutive rows form one pair querying the same person. Control averages cross-entropy over both rows. Treatment adds 0.5 times symmetric Jensen–Shannon divergence. For differing oracle classes, swap the corresponding coordinates of the first probability vector before computing divergence; equal classes use identity. Log-softmax and logaddexp are evaluated in FP32 with finite-loss/gradient checks. Supervised labels never enter inference inputs. Wrong predictions can be consistently related; cross-entropy remains essential. This is an untested adaptation, not a guaranteed reasoning mechanism or novelty claim.

Both arms have identical prompts, labels, pair order, token exposure, microbatches, update schedule and parent weights. Each epoch contains 6,048 old-format question presentations (1,008 families, each of three questions repeated as an identity pair) and 6,048 multi-entity presentations (84 groups per size, three label rotations, two versions of every query). Total 12,096 presentations or 6,048 pairs per epoch; three epochs, 36,288 presentations, 18,144 pairs and 1,134 updates per arm. Identity old-format pairs retain supervision; duplicate presentations are not independent observations. Pair ordering is deterministically shuffled each epoch; four pairs per microbatch and sixteen pairs per effective batch. Model/backbone learning rate 2e-5; head 1e-4; weight decay .01; clip 1; warmup .05. Train BF16 autocast with FP32 weights/loss; final aggregate inference uses BF16, reference exports use FP32. Both arms compute the same forward pass and diagnostic JS; only its gradient coefficient differs.

## Selection, endpoint and stopping rule

Candidates at updates 0, 250, 600, 900 and 1,134; update zero is eligible. Fit temperature on selection-fit, choose minimum calibrated selection NLL, break exact ties toward earlier updates, refit on separate calibration. Development and accuracy-based selection remain descriptive. Freeze choices before final tests. No final-test tuning or selective seed choice.

Primary: treatment-minus-control complete paired-world accuracy. Bootstrap 2,000 times, resampling three-world label-rotation blocks within entity-count and edit-type strata; seed-specific 95% percentile intervals. Require lower bound >0 in both repetitions. These are finite-world sampling intervals conditional on trained runs, not training-seed uncertainty, pooled population claims or a joint 95% guarantee. Secondary: target both-answer correctness, unaffected-person both-answer correctness, each edit type, transformations, wording/depth/signed transfer and confident errors at saved temperatures. UNKNOWN is a semantic label, distinct from uncertainty or deferral.

Retention gates for treatment versus unchanged parent: complete base-world accuracy and original/counterfactual UNKNOWN accuracy, each lower interval bound >= -0.02. These are engineering checks with no familywise confidence guarantee. Report both arms versus parent on fresh complete paired worlds. If added consistency fails while paired CE helps, credit paired data. If neither arm improves faithful edits, close this fine-tuning line and choose any architecture experiment as a separate scope. No further coefficient sweep or seed expansion is part of V8.
